# Interface pixelada

Pixel Operator, de Jayvee Enaguas (HarvettFox96), versão 2018.10.04-1.
Fonte publicada pelo autor: https://www.dafont.com/pixel-operator.font
Distribuição: https://dl.dafont.com/dl/?f=pixel_operator
Licença CC0 1.0 preservada em `PixelOperator-LICENSE.txt`.

`PixelOperatorHB.ttf`: leitura com traços firmes; `PixelOperator-Bold.ttf`: títulos.
O jogo carrega cópias sem antialiasing, hinting ou posicionamento subpixel em
`scripts/ui/ui_typography.gd`. Não depende das fontes instaladas no Windows.
