# Base dos móveis v3

Sprites de móveis criados pela ferramenta integrada ImageGen e convertidos para a paleta de 33 cores do Porto. A redução conserva a proporção das imagens. Os NPCs são preservados do projeto v2.

Esta geração é a fonte de `interiors_v4`, que aplica a correção geométrica das diagonais e do apoio. A versão v3 sozinha ainda não acompanhava exatamente a projeção do piso.

Fonte: `sources/furniture.png`. Projeto editável: `interiors_v3.pxo`. Preparação: `tools/pixelorama/build_interiors_v3.gd`. Exportação: `tools/pixelorama/export_interiors_v3.ps1`.
